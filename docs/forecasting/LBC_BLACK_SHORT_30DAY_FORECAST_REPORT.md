```

```

#### Step 2: Calculate Safety Stock

**Safety Stock Formula:**
```
Safety Stock = (Lead Time × Daily Demand) × Safety Factor

Where:
- Lead Time = 14 days (typical supplier lead time)
- Daily Demand = 87 units ÷ 30 days = 2.90 units/day
- Safety Factor = 1.5x (to account for demand variability)

Lead Time Demand = 14 days × 2.90 units/day = 40.62 units
Safety Stock = 40.62 × 1.5 = 60.93 ≈ 61 units
```

**Rationale for Safety Stock:**
- **Lead Time (14 days):** Time from placing order to receiving stock
- **Safety Factor (1.5x):** Buffer for:
  - Demand spikes (bulk orders can be 18+ units in a day)
  - Supplier delays
  - Quality issues requiring returns
  - Unexpected school events (sports days, new student enrollments)

#### Step 3: Calculate Required Inventory

```
Required = Forecast_next_30_days + SafetyStock

Required = 87 + 61
Required = 148 units
```

#### Step 4: Calculate Inventory Gap

```
Gap = Required - Available

Gap = 148 - 110
Gap = 38 units SHORT
```

Safety Stock = 40.62 × 1.5 = 60.93 ≈ 61 units
```

**Required Inventory:**
```

Required = 87 + 61 = 148 units
```

**Inventory Gap:**
```
Gap = Required - Available
Gap = 148 - 110 = 38 units SHORT
```

**Days of Stock:**
```
Days = Available ÷ Daily_Demand
Days = 110 ÷ 2.90 = 37.9 days
```

**Recommended Order:**
```
Order = CEILING(Gap ÷ Case_Pack_Size) × Case_Pack_Size
