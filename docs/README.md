# SASPulse Documentation

This folder contains all project documentation organized by topic.

## 📁 Folder Structure

### `/forecasting`
Sales forecasting system documentation, analysis reports, and bug fixes.

**Files:**
- `CRITICAL_BUG_PRODUCT_VARIATIONS_NOT_FORECASTED.md` - Bug report on variation-level forecasting issues
- `FIXES_IMPLEMENTED_SKU_VARIATION_FORECASTING.md` - Implementation details of SKU-level forecast fixes
